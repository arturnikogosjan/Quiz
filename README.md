# Quiz-App – Webentwicklungsprojekt

## Projektbeschreibung
Eine einfache Quiz-Webanwendung, bei der Nutzer vier Fragen beantworten und ihr Wissen testen können.

## Funktionen
- Vier Quizfragen beantworten
- Antwortmöglichkeiten auswählen
- Wissen auf spielerische Weise testen
